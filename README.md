# 🌱 KrishiRakshak AI | Smart Farming

**KrishiRakshak AI** is a smart farming platform designed to help Indian farmers make better and faster farming decisions using AI-powered crop analysis, risk assessment, weather information, market insights, and practical recommendations.

## 🚜 Features

* 🤖 **AI Farming Assistant** — Ask farming-related questions and get practical guidance.
* 📷 **AI Crop Scan** — Analyze crop/leaf images and identify visible health concerns.
* 🛡️ **Crop Risk Analysis** — Get Low, Medium, or High risk assessment.
* 📋 **Action Plan** — Receive practical steps to take for the crop.
* 🌤️ **Weather Insights** — Check weather conditions for farming decisions.
* 📊 **Market Insights** — View agricultural market price information.
* 🎙️ **Voice Interaction** — Ask questions using voice and receive spoken responses.
* 🌐 **Hindi & English** — Farmer-friendly multilingual interface.
* 📱 **Responsive Dashboard** — Designed for desktop and mobile screens.

## ⚙️ Run Locally

### Start Backend

```bash
cd server
npm install
node server.js
```

### Start Frontend

Open the project using a local web server.

The application connects the frontend with the backend to provide AI-powered features.

## 🔐 Security

API credentials are stored privately using environment variables and are **not included in the public repository**.
